NPCs

An NPC is a rule container (asset container with rule metadata and flags) placed in a zone.

Asset Container

NPCsDownloader spawns an NPC only when its asset container has all of these assets. Without one of them the NPC is skipped. An asset that fails to download leaves the zone loading screen hanging.
Prefab_Unity3D with the 3D Prefab group is the NPC model. Its res_name is the NPC name, and it must be the CMS name NPC_<Name>.
Location_Unity3D is a prefab with the spawn position. With several locations, the client picks SpawnPoint_<n>, then SpawnPoint_Default, then the first one.
Text is the NPCAnimations treenode (idle animations, emotes and chat bubbles).
Relationship_Text is the NPCRelationships treenode (relationship levels).

Optional assets: Localized_Data is the JSON with the name label, FacePlayer, AllowTasks, Size and ScreenOffset. LocalizedText, Config_Text and Images are used by NPC stores, Intro_Unity3D is spawned with the NPC while Spring Bay is locked.

Fields

The client reads only the zone, the locked flag and the asset map of an NPC.
Zone: home yard NPCs belong to the HardCodedZoneId (4, 16, 0, 2937912) zone, and are shown only in the player's own yard, and only when unlocked.
Locked: a locked NPC shows the members-only icon and offers no quests.
