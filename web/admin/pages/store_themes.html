Store Themes

The World Shop categories and subcategories sent in the GetStoreThemes message.

Asset Container

Text is the theme name, Images is the theme icon.

Fields

Parent Theme: empty for a category on the left side of the shop, set for a subcategory.
Ordinal: the order of the themes inside their parent.
Items: the items of the theme, the client requests them by the subcategory. An item is put in a theme on the Items page, an item without a theme is not sold in the World Shop.
